# 02. 部署方案与实践

## 官方推荐路径
- 起步入口：https://docs.openclaw.ai/start/getting-started
- 主仓库安装说明：https://github.com/openclaw/openclaw
- 官方推荐方式（按 README）：使用 CLI onboarding 流程进行初始化与守护进程安装。

## 部署路线图（按成熟度）
1. `官方 CLI + 本机守护`（优先）
2. `Docker 化部署`（适合服务器与容器环境）
3. `Nix / Ansible`（适合可重复基础设施）
4. `PaaS/平台集成`（1Panel、Umbrel、Cloudflare 方案）
5. `移动端/低功耗设备`（Termux/Android 分支方案）

## 选择建议

### 个人本地使用
- 首选官方 CLI 流程。
- 优点：与官方功能迭代同步最快，文档一致性最高。

### 团队/服务器运行
- 优先 Docker + IaC（Nix/Ansible）组合。
- 原因：可重建、便于版本管理和回滚。

### 国内 IM 场景
- 需要重点评估第三方“中文整合版/一键版”的安全性和维护连续性。
- 建议只使用“可审计脚本 + 最小权限密钥”方式接入。

## 部署尽调检查项
- 仓库最近更新时间是否持续活跃。
- License 是否明确。
- 是否存在硬编码密钥、明文配置、远程脚本一键执行风险。
- 是否明确支持版本与迁移策略。
- 是否有社区问题处理能力（Issue 响应/PR 合并）。
