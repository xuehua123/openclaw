# 07. 尽调方法与筛选标准

## 数据来源
- GitHub 官方 API（组织、仓库、release、fork、search）
- OpenClaw 官方站点快照：`https://openclaw.ai`
- OpenClaw 文档快照：`https://docs.openclaw.ai/start/getting-started`

## 检索策略
- 官方面：`org:openclaw`
- 广义生态：`topic:openclaw`
- 关键词生态：`openclaw in:name,description,readme`
- 主题切片：
  - 插件：`openclaw plugin ...`
  - 技能：`openclaw skill ...`
  - 面板：`openclaw panel OR dashboard ...`
  - 部署：`openclaw deploy OR installer ...`
  - 安全：`openclaw security OR secure OR guard ...`

## 处理流程
1. 汇总多查询结果。
2. 按 `full_name` 去重，保留最高 star 记录。
3. 过滤高相关仓库（名称/描述/topics 包含 OpenClaw 相关关键词，或官方组织仓库）。
4. 自动分类为：官方、部署、插件技能、面板、安全、替代实现、文档案例、其他。
5. 导出 JSON/CSV 供人工复核。

## 关键输出文件
- `data/openclaw_related_dedup_classified.json`
- `data/openclaw_related_dedup_classified.csv`
- `data/openclaw_related_top200.csv`
- `data/summary.json`

## 自动刷新
```powershell
cd OpenClaw_中文调研
powershell -ExecutionPolicy Bypass -File .\scripts\refresh_openclaw_data.ps1
```

## 方法局限
- GitHub 检索会混入“仅提及 OpenClaw”的低相关仓库。
- 自动分类依赖关键字，存在误判。
- 对关键项目需人工逐仓核验（README、代码、issue、release、license）。
