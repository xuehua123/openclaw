# 00. 快速结论

## 结论摘要
- `OpenClaw` 的官方核心在 `openclaw` 组织，主仓库是 `openclaw/openclaw`。
- 生态已明显外溢，存在大量部署脚手架、技能库、面板、分支和“替代实现”。
- 真正高价值信息主要集中在：
  - 官方仓库和官方文档
  - 高 star 且持续更新的社区项目
  - 与你使用场景一致的连接器/面板/安全工具

## 你最该先看的入口
- 官方主仓库：https://github.com/openclaw/openclaw
- 官方组织仓库列表：https://github.com/orgs/openclaw/repositories
- 官方文档（起步）：https://docs.openclaw.ai/start/getting-started
- 官方技能目录仓库：https://github.com/openclaw/clawhub
- 官方技能归档仓库：https://github.com/openclaw/skills

## 生态判断
- GitHub 中“提及 openclaw”数量很大，但噪声高。
- 需要将仓库分为：`官方`、`部署`、`插件技能`、`面板`、`安全`、`替代实现`、`文档案例` 七类做尽调。
- 本资料库已对抓取数据做了去重分类，详见：
  - `data/openclaw_related_dedup_classified.json`
  - `data/openclaw_related_dedup_classified.csv`
