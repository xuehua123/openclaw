- IM 通道：钉钉、飞书、企业微信、微信、Discord、Telegram 等。
- 记忆层：向量库、长期记忆系统、上下文检索服务。
- 工具层：MCP 工具服务器、第三方 API 代理、自动化工作流。
- 生产力层：文件系统、知识库、DevOps、内容管线。

## 评估维度
- 兼容性：与官方当前版本是否匹配。
- 可维护性：最近提交、Issue 回应、发布节奏。
- 安全性：权限范围、密钥管理、远程执行能力边界。
- 可替换性：是否可降级回官方能力，不被单点绑定。

## 结论
- OpenClaw 的插件与技能生态是其核心护城河，但也带来供应链复杂度。
- 建议采用“白名单 + 分层隔离 + 最小权限”的引入策略。
